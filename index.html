Behind the Scene

Thank you for visiting! If you are curious about how this world was built, here is everything you need to know.

RendererThree.js — WebGL via ES modules (CDN import map)
PhysicsCustom arcade physics written from scratch (no engine)
CameraSmooth-lerp follow camera with drag orbit and wheel zoom
MinimapCanvas 2D, drawn from live world data
AudioWebAudio API — procedural honk, no sound files
MobileVirtual joystick + touch buttons
Source100% original code, MIT-friendly, in this repo

This is an original demo inspired by playful portfolio sites like Bruno Simon's. Check out threejs.org to learn Three.js!
